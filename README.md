# Northstar Market Intelligence

A responsive market dashboard for S&P 500 and global index monitoring, market leaders and laggards, sector breadth, and stock screening.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. Widgets load from TradingView and require an internet connection.

## Publish with GitHub Pages

The included Pages workflow deploys the site when changes are pushed to `main`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. Once enabled, the workflow publishes the site at `https://mauricehartery-irl.github.io/Stocks/`.

## Market data

Charts, market movers, the heatmap, ticker tape, and screener are embedded TradingView widgets. Updates are provided by TradingView; quotes may be delayed depending on exchange and entitlement. This dashboard is for research and information, not a recommendation to buy or sell any security.
